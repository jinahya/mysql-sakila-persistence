Find the actors who have appeared in at least one film of each rating (`G`, `PG`, `PG-13`, `R`, `NC-17`).
This is a relational division: for each actor, count the distinct ratings of their films, and compare that count with the number of distinct ratings over all films, taken by a subquery, so the query does not hard-code the five ratings.

.`actor/03_advanced.sql`, SAKILA_ACTOR_A_01
[%collapsible]
====
[source,sql]
----
SELECT a.*
FROM actor a
         JOIN film_actor fa ON fa.actor_id = a.actor_id
         JOIN film f ON f.film_id = fa.film_id
GROUP BY a.actor_id, a.first_name, a.last_name
HAVING COUNT(DISTINCT f.rating) = (SELECT COUNT(DISTINCT rating) FROM film)
ORDER BY a.actor_id
LIMIT 5
